# Maison Léone — maquette du site

Maquette cliquable d'un site de vente de cosmétiques naturels, réalisée pour un projet d'école.

**Maison Léone est une marque fictive.** Les prix, les boutiques, les stocks, les coffrets et le classement des meilleures ventes sont inventés. Aucune commande n'est réelle : le panier et le compte vivent dans le navigateur, rien n'est envoyé.

Le site est statique : des pages HTML, des feuilles de style, du JavaScript, et les soins en 3D (Three.js, modèles faits dans Blender).
